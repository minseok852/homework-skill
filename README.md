# homework-skill

과제 보고서와 수업 발표 PPT를 만들 때마다 같은 작성 기준을 설명하는 일을 줄이기 위해 만든 개인용 AI 스킬 모음입니다. 기존에 제출한 과제 보고서와 캡스톤 발표에서 받은 피드백을 바탕으로 정리했습니다.

## 스킬 목록

| 스킬 | 작성 방식 |
|---|---|
| [과제 보고서](skills/write-assignment-report/SKILL.md) | `1) 소스 → 2) 설명 → 3) 결과` 형식을 따릅니다. 전체 코드와 실행 캡처는 제가 넣고, AI는 설명할 코드 한두 줄이나 함수 일부를 보여준 뒤 바로 아래에서 동작을 줄별로 설명합니다. 필요한 표와 수식을 추가하고, 느낀 점이나 소감은 임의로 덧붙이지 않습니다. |
| [수업 발표 PPT](skills/build-class-presentation/SKILL.md) | 문제 상황, 해결 방안, 확인한 결과를 그림 중심으로 보여줍니다. 사용할 이미지나 캡처를 먼저 확인하고, 이미지가 없으면 글로 받은 내용을 도형과 짧은 라벨로 표현합니다. 한 장에 메시지 하나를 담고, 큰 그림에 한 줄 설명을 붙입니다. 글이 많아지면 명사구 불릿으로 정리하고, 그래도 넘치면 슬라이드를 나눕니다. |

## 설치 방법

### ChatGPT에서 설치

1. GitHub에서 **Code → Download ZIP**으로 저장소를 내려받아 압축을 풉니다.
2. `skills/` 아래의 `write-assignment-report`와 `build-class-presentation` 폴더를 각각 ZIP으로 압축합니다. 각 ZIP에 해당 스킬 폴더와 그 안의 `SKILL.md`가 들어 있어야 합니다.
3. ChatGPT 사이드바에서 **플러그인 → 스킬 → 만들기 → 컴퓨터에서 업로드**로 이동해 ZIP을 하나씩 업로드합니다. 업로드 후 **설치됨** 목록을 확인합니다.

스킬 탭과 업로드 메뉴의 제공 여부는 요금제와 워크스페이스 권한에 따라 달라집니다. 설치 메뉴를 사용할 수 없다면 일반 대화에 필요한 `SKILL.md`를 첨부하고 “이 파일의 작성 기준을 따라줘”라고 요청할 수 있습니다. [ChatGPT 스킬 공식 안내](https://help.openai.com/en/articles/20001066-skills-in-chatgpt)

### 로컬 Codex에서 설치

압축을 푼 저장소의 `skills/`에서 두 스킬 폴더를 통째로 복사합니다. 사용 범위에 맞춰 아래 경로 중 하나에 넣고 Codex에서 새 세션을 엽니다.

| 사용 범위 | 복사할 위치 |
|---|---|
| 이 컴퓨터의 여러 프로젝트 | `~/.agents/skills/` · Windows는 `%USERPROFILE%\.agents\skills\` |
| 특정 프로젝트 | 해당 프로젝트의 `.agents/skills/` |

CLI나 IDE에서 직접 선택하려면 `$write-assignment-report` 또는 `$build-class-presentation`을 입력합니다. [Codex 스킬 공식 안내](https://learn.chatgpt.com/docs/build-skills)

## 요청 예시

- **과제 보고서** — “이 최종 코드로 보고서의 `2) 설명`을 써줘. 설명할 코드 조각 아래에 각 줄의 동작을 풀어주고, 문제에서 요구한 계산 표도 넣어줘.”
- **수업 발표 PPT** — “이 문제를 어떻게 해결했는지 발표용 PPT로 구성해줘. 사용할 캡처가 있는지 먼저 확인하고, 해결 과정이 그림에서 바로 보이게 해줘.”

## 유의사항

- 설치한 스킬을 현재 대화 환경에서 사용할 수 있고 요청이 스킬의 설명과 맞으면 AI가 자동으로 선택할 수 있습니다. 일반 Chat과 Work에서는 각 환경의 지원 여부를 확인합니다. [스킬 호출 방식](https://learn.chatgpt.com/docs/build-skills#how-chatgpt-and-codex-use-skills)
- 위의 수동 설치 방식에서는 GitHub의 변경 사항을 반영하려면 설치한 사본도 갱신해야 합니다. 로컬 Codex는 최신 폴더를 다시 복사하고, ChatGPT에서는 등록한 스킬을 최신 지침으로 업데이트합니다.
- 과제에 지정 양식이나 채점 기준이 있으면 해당 자료를 함께 제공하세요. 코드 설명은 최종 코드를 기준으로 작성하고, 발표 자료에는 실제로 확인한 화면이나 수치를 사용합니다.
